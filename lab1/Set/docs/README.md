# Unordered Cantor Set

## Project description
This project implements an unordered set in C++.

## Features
- Add and remove elements
- Check whether an element exists
- Calculate union, intersection, and difference
- Compare two sets
- Copy and assign sets
- Convert sets to and from text
- Calculate a power set
- Use overloaded operators
- Interact with the program through a console menu

## Source files
- `Set.h` — class declaration
- `Set.cpp` — implementation of set operations
- `main.cpp` — console menu and program entry point

## Build
Open a Visual Studio Developer PowerShell terminal in the project directory and run:

```powershell
cl /EHsc Set.cpp main.cpp /Fe:Set.exe
```

## Run
```powershell
.\Set.exe
```
